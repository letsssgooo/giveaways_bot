# Бот розыгрышей

Telegram-бот для промоакций партнеров: [@giveaways_letsssgooo_bot](https://t.me/giveaways_letsssgooo_bot).

## Возможности

- Выдача промокодов и регистрация в розыгрышах с проверкой подписки.
- Ежедневные и финальный розыгрыши, учет до 10 шансов участника.
- Подтверждение результатов, уведомление победителей и получение призов.
- Админка в Telegram: акция, партнеры, расписание, материалы и доступы.
- Рассылки, статистика и CSV-выгрузки участников и победителей.

Стек: Go, Telegram Bot API, PostgreSQL, Flyway, Docker Compose.

## Запуск

Нужны Docker с Compose и Make.

```sh
cp -n .env.example .env
chmod 600 .env
```

Заполните `.env`:

- `TELEGRAM_BOT_TOKEN` — токен бота.
- `POSTGRES_PASSWORD` — пароль PostgreSQL.
- `DOCKER_DATABASE_URL` — URL БД с хостом `postgres`, портом `5432` и учетными данными из `POSTGRES_*`. Специальные символы в логине и пароле кодируются для URL.
- `ADMIN_TELEGRAM_IDS` — числовые Telegram ID основных организаторов через запятую. При первом запуске укажите хотя бы одного организатора, чтобы получить доступ к настройкам.

В Compose значение `DOCKER_DATABASE_URL` передается приложению как `DATABASE_URL`; отдельный `DATABASE_URL` в `.env` для этого запуска можно оставить пустым. Затем выполните:

```sh
make docker-up
```

Compose поднимет PostgreSQL, применит миграции и запустит бота. На один токен запускается один экземпляр бота.

- `make status` — состояние контейнеров.
- `make docker-logs` — логи бота.
- `make docker-stop` — остановка бота.

Остальные команды — в [Makefile](Makefile). Для запуска через `make run` нужны Go версии из [go.mod](go.mod), доступная БД с примененными миграциями и переменные окружения, включая `DATABASE_URL`. Этот способ не читает `.env` автоматически.

## Управление в Telegram

Команда `/admin` отображается в меню только у организаторов и администраторов партнеров. Организаторы управляют всей акцией, администраторы партнеров — только назначенными им партнерами. При ручном вводе команды права также проверяются.

Дополнительные роли назначаются через админку по числовому Telegram ID или `@username`. Для добавления по нику пользователь должен сначала отправить боту `/start`. Основные организаторы из `ADMIN_TELEGRAM_IDS` изменяются через конфигурацию.

Общие команды: `/start`, `/menu`, `/help`, `/cancel` и `/prizes`. `/cancel` отменяет текущий ввод, `/prizes` открывает получение назначенных пользователю призов.

Перед рабочим запуском настройте через `/admin` акцию, партнеров, расписание, призы и материалы, загрузите промокоды и проверьте права бота в каналах партнеров. Даты и время в админке указываются по Москве.
